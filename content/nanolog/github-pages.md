Shifted my site from **arkovyx.netlify.app** to **arkovyx.github.io**.

Netlify had some token limit issues which I didn't want to deal with. GitHub Pages gives me way better management of the site and is overall the best way to host without owning your own server.

No more build limits. No more token nonsense. Just push and deploy.

Plus, everything is in one place now — code, hosting, and deployment. Clean and simple.
